# Super Simple Speedo v13.3.2

## Simpler transport front screen

- Replaces the confidence-heavy transport badge and classifier metric overlay with two simple front-screen results:
  - `Vehicle detector: Bus` (or the current detected vehicle family)
  - `Line detector: 89` (or the current fresh Swiss PT line match)
- Removes classifier percentages, fit scores, road-confirmation percentages, station distance and confidence formula from the normal driving screen.
- Keeps all detailed classifier/timetable evidence in Diagnostics / Live Intelligence and exported logs.
- Retains the existing 25-second `Waiting for movement…` behaviour without changing the internally retained vehicle hypothesis.
- Leaves all vehicle-classifier thresholds, hysteresis, Swiss PT matching, walking logic and GPS/rail-recovery algorithms unchanged.
- Updates the regression gate to protect the simplified detector labels and ensure the old detailed transport-metrics overlay stays hidden.
