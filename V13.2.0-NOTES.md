# Super Simple Speedo v13.2.0 — release integrity and startup recovery

- Rebuilt from v13.1.0 Live Intelligence.
- Moves the safety disclaimer to the launch screen; old in-drive node remains hidden.
- GPS starts immediately on launch; screen wake lock can no longer block startup.
- Startup GPS state is armed before watchPosition() to prevent a fast-first-fix race.
- 12-second startup watchdog releases a stalled launch screen instead of freezing forever.
- Adds local capture of early runtime errors for iOS standalone diagnostics.
- Service-worker registration is now tied to the application version, not hard-coded v12.2.
- Includes a versioned service-worker source which removes older Speedo caches on activation.
- Navigation is network-first with no-store; APIs are never service-worker cached.
- A newly activated worker performs one guarded reload so the UI and code come from one release.
