# Super Simple Speedo v13.1.0 — Live Intelligence

Built from v13.0.1.

## Diagnostic mode
- Added a real-time **Live Intelligence** terminal feed.
- Shows GPS samples, Swiss public transport connectivity, nearby-stop searches, stationboard requests, API latency, candidate races, classifier changes and ground-truth labels.
- Added live vehicle hypothesis bars for Walking / Bus / Car / Tram / Train.
- Adds a playful `>>> WE'RE IN` only after the Swiss public-transport API actually responds successfully.
- Adds `>>> MATCH ACQUIRED` only when a timetable candidate reaches at least 60% confidence.
- New transit query details are retained in the persistent TSV archive for later analysis.

## Existing v13 behaviour retained
- 30-day IndexedDB diagnostic archive.
- Ground-truth mode labels.
- Swiss timetable evidence layer.
- iOS share-sheet-first log export.
- Startup public transport connectivity check.
