# Super Simple Speedo v13.3.3

## Quieter Live Intelligence

- Hides `WAKE_LOCK` housekeeping events from the on-screen Live Intelligence feed.
- Keeps all `WAKE_LOCK` events in the underlying diagnostic history and exported logs for debugging background/lock-screen problems.
- Does not change wake-lock behaviour, transport classification, Swiss public-transport matching, walking detection, GPS handling, or road matching.
- Adds a regression check protecting both sides of the decision: wake-lock logging must remain present, while Live Intelligence must filter it from the visible feed.
