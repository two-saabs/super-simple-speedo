# Super Simple Speedo v13.1.3 — iOS startup sequencing fix

- Fixes a startup stall seen after tapping “Let’s go!” on iOS.
- GPS startup no longer waits for the Screen Wake Lock promise to resolve.
- Screen Wake Lock is still requested from the user gesture, but it is now fire-and-forget so it cannot block GPS.
- Marks startup GPS state as pending before registering `watchPosition`, preventing a very fast first location fix from racing ahead of the launch state.
- Keeps the startup disclaimer placement from v13.1.1 and the defensive launch-button wiring from v13.1.2.
- No classifier, Swiss public-transport matching, logging, or Live Intelligence logic changes.
