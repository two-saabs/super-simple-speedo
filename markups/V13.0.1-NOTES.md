# Super Simple Speedo v13.0.1

- Fixes Swiss public-transport lookups on production by allowing `https://transport.opendata.ch` in the Netlify Content Security Policy.
- Startup now shows `Connecting to public transport data…` only when Experimental Mode + Transport Detective are enabled, and that message corresponds to a real API connectivity check after the first GPS fix.
- Startup action renamed from `Let’s drive` to `Let’s go!`.
- Diagnostic archive action renamed to `Export all .tsv`.
- On devices that support file sharing (notably iOS/PWA), diagnostics now use the native share/save sheet first instead of an `<a download>` navigation that can destabilise the standalone app. Browser download remains as fallback.
- Adds `TRANSIT_SERVICE` and `DIAGNOSTIC_EXPORT` diagnostics for easier troubleshooting.

Observed from the first v13 field log:
- Walking classification reached 97% in the UI.
- Three public-transport lookups failed with Safari `Load failed`; this was consistent with the existing CSP permitting Geoapify but not transport.opendata.ch.
- Persistent archive survived multiple app resume/reopen events and included a manual ground-truth label.

Quality gate: 0 failures / 0 warnings.
