# Super Simple Speedo v13.1.2 — iOS launch-button hotfix

- Keeps the driver-responsibility disclaimer on the startup screen.
- Makes the disclaimer non-interactive so it can never intercept taps.
- Gives the “Let’s go!” button an explicit interactive stacking layer and `touch-action: manipulation`.
- Wires the launch action near the start of JavaScript initialization so a later runtime error cannot leave the startup button inert.
- Adds an iOS `touchend` fallback while guarding against duplicate starts.
- No classifier, transport matching, logging, or Live Intelligence changes.
