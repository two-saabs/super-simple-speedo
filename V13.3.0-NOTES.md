# Super Simple Speedo v13.3.0

## Rail GPS recovery + Swiss transit matching fixes

- Adds conservative long-baseline speed recovery when native browser speed disappears and strong train/tram evidence already exists.
- Recovery uses multiple coordinate samples over 8–30 seconds and rejects weak/noisy estimates rather than trusting single GPS jumps.
- Adds diagnostic source `TRANSIT_LONG_BASELINE` and recovery metadata.
- Recognises Swiss public-transport tram category `T` (bus `B` was already recognised).
- Preserves S-Bahn line labels such as `S4` instead of displaying only `4`.
- Keeps all normal native-GPS and derived-speed safety gates unchanged outside strong rail context.
